    Teletext Editor — Quick Start

    Create authentic Teletext pages with exact control codes and mosaic graphics.

    Modes

    Text (F1) — Click to place cursor, then type. Arrow keys navigate.

    Control (F2) — Type text normally, or click the control code grid to insert color changes, flash, double-height, etc.

    Mosaic (F3) — Click and drag to paint sextant pixels. Each cell is a 2×3 grid. Right-click/drag to erase.

    Inspect (F4) — Click cells to see raw byte values.

    How Teletext Color Works

    Insert a color control code into the row. It takes one cell (shows as space) and changes the color for everything after it. Shift+1-8 inserts mosaic colors.
