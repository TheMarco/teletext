Teletext System BComplete WST Implementation

A fully functional Teletext system built from scratch in TypeScript. Renders pixel-perfect pages through an ETSI EN 300 706 compliant state machine with a 5-pass CRT shader.

What You're Looking At

This viewer displays a teletext service with 36+ pages of content from ai-created.com — products, stories, lab notes, and more — all rendered as authentic teletext.

Type a 3-digit page number (hex) to navigate. Use the colored fastext buttons to follow links. Arrow keys flip through subpages on multi-page articles.

Capabilities

  • Full Level 1 control code state machine
  • T42 import (real broadcast captures)
  • T42 export (broadcast-compatible)
  • Visual page editor with mosaic painting
  • Bitmap-to-mosaic converter (full color)
  • 5-pass WebGL CRT shader
  • Hamming 8/4 encode/decode
  • Packet compiler (AST → wire format)
